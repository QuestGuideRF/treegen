# treegen — генератор tree.md

Утилита на Python: рекурсивно обходит папку и формирует файл **tree.md** в виде дерева в псевдографике (├──, │, └──) с краткими описаниями файлов и каталогов.

## Требования

- Python 3.7+

Зависимостей нет, только стандартная библиотека.

## Установка

Скопируйте `treegen.py` в нужную папку или добавьте её в `PATH`.

## Запуск

```bash
python treegen.py [папка] [опции]
# или
py treegen.py [папка] [опции]
```

По умолчанию обходится текущая папка (`.`), результат пишется в **tree.md** в корне обхода.

## Опции

| Опция | Описание |
|-------|----------|
| `root` | Корневая папка для обхода (по умолчанию текущая) |
| `--tree-out FILE` | Куда сохранить дерево (по умолчанию `tree.md` в корне обхода) |
| `--dry-run` | Не записывать файл, только вывести план в консоль |
| `--force` | Разрешить перезапись существующего файла |
| `--max-depth N` | Ограничить глубину рекурсии |
| `--exclude PATTERN` | Исключить файлы/каталоги по имени (можно указать несколько раз) |
| `--verbose`, `-v` | Подробный вывод в stderr |

## Примеры

```bash
# Дерево текущей папки → tree.md
python treegen.py

# Дерево папки project, сохранить в docs/structure.md
python treegen.py project --tree-out docs/structure.md

# Только посмотреть, что получится (файл не создаётся)
python treegen.py --dry-run

# Перезаписать существующий tree.md
python treegen.py --force

# Не глубже 2 уровней, без .git и __pycache__
python treegen.py --max-depth 2 --exclude .git --exclude __pycache__

# Дерево в корне диска D в файл D:\tree.md
python treegen.py D:\ --tree-out D:\tree.md
```

## Откуда берутся описания

- **Файлы:**
  1) первая строка-заголовок (Markdown `#`, HTML `<title>`/`<h1>`, docstring `"""`/`'''`);
  2) первая строка комментария (`#`, `//`, `/* */`, `<!-- -->`, `REM`/`::` и т.п.);
  3) если ничего не подошло — подставляется тип файла (Python, JavaScript, PHP и т.д.) или «Файл».

- **Каталоги:**
  1) описание из README/index в этом каталоге;
  2) иначе — «Каталог».

Большие файлы читаются только в начале (ограничение по размеру), бинарные пропускаются.

## Пример вывода tree.md

```text
# Дерево каталогов

├── includes/                 # Каталог
│   ├── config.php            # Конфиг из .env
│   ├── db.php                # PDO, getDB()
│   └── auth.php              # Проверка авторизации
└── treegen.py                # Утилита для генерации tree.md...
```
